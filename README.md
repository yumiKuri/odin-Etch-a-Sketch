# Etch-a-Sketch - The Odin Project
## Overview
A browser-based drawing grid implemented with vanilla JavaScript and CSS Grid, supporting multiple drawing modes and dynamic grid resizing.

## Purpose
- Practice DOM manipulation
- Apply event delegation and event bubbling
- Build a state-driven UI without frameworks

## Features

- Adjustable grid size
- Drawing modes: black (default), grayscale, rainbow
- Erase mode
- Reset functionality

## Tech Stack
- HTML
- CSS (Grid)
- JavaScript (ES6)

## Notes
- The grid layout is implemented using CSS Grid instead of Flexbox, deviating from the original Odin Project instructions.
- Styling is intentionally minimal and focused on usability rather than visual polish.
